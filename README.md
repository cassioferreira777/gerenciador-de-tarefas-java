\# Sistema de Cadastro de Tarefas



Projeto desenvolvido em Java para gerenciar tarefas por meio de um menu interativo no terminal.



\## Funcionalidades



\- Adicionar tarefas

\- Listar tarefas cadastradas

\- Visualizar o status das tarefas

\- Concluir tarefas

\- Validar entradas do usuário



\## Tecnologias utilizadas



\- Java

\- Git

\- GitHub



\## Como executar



Compile o programa:



```bash

javac Main.java

```



Execute:



```bash

java Main

```
